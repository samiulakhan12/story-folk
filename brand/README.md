# StoryFolk brand assets

| File | Use |
| --- | --- |
| `storyfolk-icon.svg` | App icon, favicon, avatars, social profile |
| `storyfolk-logo-on-light.svg` | Horizontal logo for light backgrounds |
| `storyfolk-logo-on-dark.svg` | Horizontal logo for dark backgrounds |
| `storyfolk-mark-mono-dark.svg` / `-white.svg` | Single-colour glyph (print, watermarks, embossing) |
| `favicon.ico` | 16/32/64 px favicon |
| `png/` | Raster exports (icon 16–1024 px incl. 180 px Apple touch icon, logos @2x) |

## Colours

| Token | Hex |
| --- | --- |
| Brand violet (icon background) | `#6D5BF6` |
| Flame accent | `#FFC542` |
| Ink (wordmark on light) | `#0F172A` |

Style: fully flat vector, solid fills only (no gradients, shadows or highlights).

Wordmark: Inter Display Bold, converted to outlines (no font dependency).

Keep clear space around the logo equal to half the icon's height, and don't
render the icon below 16 px.
